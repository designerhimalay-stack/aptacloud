Why AWS security

WhychooseAWSsecurityservices?

Six areas of AWS security, grouped the way the work is done: protect what you run, detect what goes wrong, and prove you comply.

Protect

Data, networks, and applications secured before anything happens.

  • Data security

    Sensitive data in Amazon S3 found and protected with Amazon Macie, managed across accounts from one administrator, and collected in Amazon Security Lake. Keys held in AWS CloudHSM.

    • Amazon Macie
    • Amazon Security Lake
    • AWS CloudHSM

  • Network security

    SSL/TLS and private certificates managed with AWS Certificate Manager, and traffic controlled with AWS Network Firewall and policies set in AWS Firewall Manager across your VPCs.

    • AWS Certificate Manager
    • AWS Network Firewall
    • AWS Firewall Manager

  • Application security

    Network layers protected from DDoS attacks with AWS Shield across EC2, Elastic Load Balancing, and Amazon CloudFront; web apps protected from bots with AWS WAF rules; and fine-grained authorisation with Amazon Verified Permissions.

    • AWS Shield
    • AWS WAF
    • Amazon Verified Permissions

Detect

Threats and weak spots found early, and acted on.

  • Threat detection and response

    Amazon Detective investigates log data with machine learning and graph analysis to find root causes, and AWS Security Hub brings findings from Amazon Inspector, Macie, and GuardDuty into one place.

    • Amazon Detective
    • AWS Security Hub
    • Amazon GuardDuty

  • Vulnerability management

    Amazon Inspector scans workloads automatically, including through the Systems Manager agent and Amazon ECR, with every finding in one console and a clear report on your assets.

    • Amazon Inspector
    • AWS Systems Manager

Comply

Evidence on hand whenever an auditor asks.

  • Monitoring and reporting

    AWS Audit Manager maps your resources to industry requirements, or to a framework we customise for you, with full security reports and risk assessment from the AWS Management Console.

    • AWS Audit Manager
    • AWS CloudTrail
